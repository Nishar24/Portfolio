# Md Nishar Alam — Portfolio

## 🚀 Setup

```bash
npm install
npm run dev
```

## 📸 Add Your Photo

1. Copy your photo to `/public/photo.jpg`
2. The hero section will automatically show it

## 🏗️ Build for Production

```bash
npm run build
# Files will be in /dist folder — deploy to Vercel/Netlify
```

## 🛠️ Tech Stack
- React 19 + Vite 8
- Tailwind CSS 3
- No extra dependencies
